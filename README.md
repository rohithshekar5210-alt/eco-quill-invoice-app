# Eco Quill Invoice Generator

## Project Overview

Eco Quill Invoice Generator is a Python-based business automation application developed for Eco Quill Bio Bags.

The application allows users to generate professional GST invoices, calculate taxes automatically, generate PDF invoices, maintain invoice history, and send invoices through email.

## Features

### Customer Details
- Customer Name
- Customer Address
- Phone Number
- WhatsApp Number
- Email Address
- GSTIN

### Invoice Details
- Invoice Number
- Invoice Date
- Place of Supply
- Payment Status

### Product Details
- Product Name
- HSN/SAC Code
- Quantity
- Rate
- GST Percentage

### Automated Calculations
- Taxable Value
- GST Amount
- Packing Charges
- Grand Total
- Amount in Words

### PDF Invoice
- Professional GST Invoice Format
- Company Information
- Customer Information
- Product Summary
- Tax Summary
- Bank Details
- Terms & Conditions
- Authorized Signature Section

### Email Functionality
- Send invoice to Eco Quill email
- Send invoice to customer email

### WhatsApp Support
- Generate WhatsApp Invoice Message Link
